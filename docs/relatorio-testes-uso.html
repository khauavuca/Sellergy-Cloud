Relatório de testes de uso

0 de 0 corrigidos

O que foi feito (25/11/2026): 4 agentes testaram o sistema pela API como "cliente maluco", em 5 negócios de teste (salão, loja, clínica, studio e um negócio só para testar isolamento), e eu usei as telas no navegador, no local e no site ao vivo. Foram cerca de 1.300 casos.

O que mais pesa: (1) um negócio conseguir mexer ou ver dados de outro; (2) clique duplo / pedidos ao mesmo tempo duplicando venda, estoque, cupom e agendamento; (3) telas de cadastro que quebram para conta nova; (4) erros mostrando código interno do servidor.

Como usar: marque a caixinha quando o item for corrigido e conferido. As marcações ficam salvas neste navegador.
